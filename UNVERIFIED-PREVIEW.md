# Unverified subsystem code preview

This archive contains software-checked proposals, not a verified complete robot implementation. The saved review is evidence of a software review, not an authenticated robot approval.

Source geometry, mechanism ownership, omitted CAD bodies, electrical modes, wiring, directions, measurements, tuning and physical operation remain unverified. Check the exclusions and required configuration in verification/preview.json before integrating any controller.

The exact source context and emitted files are retained for reproduction. From the CAD-to-Code repository, run scripts/verify-preview-export.ts with this ZIP to recheck its inventory, source binding, trusted Java contract, official FTC SDK compilation and supported behavior scenarios. This does not establish physical correctness.
